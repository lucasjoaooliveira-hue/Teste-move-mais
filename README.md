# Move+ Moda Fitness — Catálogo

Site estático para catálogo interno.

## Como usar no GitHub
1. Crie um repositório no GitHub.
2. Envie `index.html` e `logo-move-plus.png`.
3. Em Settings > Pages, escolha Deploy from a branch.
4. Selecione a branch principal e a pasta `/root`.
5. Salve e aguarde o GitHub Pages publicar.

## Recursos
- Cadastro de produto com foto real.
- Nome, tamanho, cor e preço.
- Busca e filtros.
- Marcar/desfazer vendido.
- Seleção de produtos.
- Geração de catálogo para impressão/salvamento como PDF.
- Dados mantidos no navegador por localStorage.
